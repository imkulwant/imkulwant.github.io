Things I build outside my day job

Event-driven payments

payment-system

A payment pipeline built the way real processors work: authorise first, capture later, and keep an audit trail of every state change.

  • Idempotency keys on every request, so a retried call returns the same payment instead of creating a new one.
  • Kafka between the steps: payment-api publishes, payment-worker authorises and captures, ledger-service records.
  • Retry topics and a circuit breaker around the external provider, so a slow provider doesn't stall the pipeline.
  • Append-only ledger of every status change, with ShedLock for locking across instances.

Kotlin · Spring Boot 4 · Kafka · MySQL · Liquibase · Resilience4j

Edge gateway

api-gateway

The front door for backend services: every request is rate-limited, protected by a circuit breaker and traced end to end.

  • Rate limiting in Redis, keyed by client IP, shared across gateway instances.
  • Resilience4j circuit breaker with a fallback route when a backend is failing.
  • Distributed tracing with Micrometer and OpenTelemetry, exported to Zipkin.
  • Health probes and OpenAPI through Actuator and Swagger UI.

Java 21 · Spring Cloud Gateway · WebFlux · Redis · OpenTelemetry

Shipped product Live

workout-tracker-pwa

An offline-first workout logger for iPhone. No server and no account: everything stays on the device.

  • React, TypeScript and IndexedDB (Dexie), installed from Safari as a home-screen app.
  • Layered architecture enforced by ESLint: only repositories touch the database.
  • End-to-end tests in iPhone WebKit with Playwright, including screenshot tests of the stats screens.
  • CI on every push: lint, type check, tests and a bundle size check, then deploy to GitHub Pages.

React · TypeScript · Vite · Dexie · Tailwind · Playwright
